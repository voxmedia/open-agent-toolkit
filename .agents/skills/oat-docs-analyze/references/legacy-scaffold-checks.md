# Legacy scaffold checks

Evaluate existing framework apps against the current contracts below. A match produces an evidence-backed finding in the analysis artifact, never an automatic rewrite. Cite the actual app path and line, the missing contract, confidence and a specific repair. Respect intentional user customization; when intent is unclear, use `ask_user`.

| Observed older shape                                                                                                                             | Finding and repair                                                                                                                                                                                                                                                                                                                                                                                | Contract source                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| Fumadocs `next.config.js` replaces `createDocsConfig` with `createMDX()({ reactStrictMode: true, turbopack: { root: __dirname } })`              | High: static-export settings are missing and `__dirname` is invalid in ESM. Recommend a manual app-config upgrade to `createDocsConfig({ basePath, turbopack: { root: dirname(fileURLToPath(import.meta.url)) } })`, preserving `output: 'export'`, `trailingSlash`, `images.unoptimized`, base path and client environment. Verify the installed docs-config supports forwarding the root first. | `@open-agent-toolkit/docs-config` factory and the current Fumadocs template |
| Layout lacks Next `metadata`, or site title differs between branding, metadata and authored headings                                             | Medium: site identity or document metadata is inconsistent. Report exact mismatches; titles belong in layout metadata and branding, not `createDocsConfig`.                                                                                                                                                                                                                                       | Fumadocs layout template and Next metadata export                           |
| Getting Started has an empty description, bare commands with no working directory, or claims lint runs when package scripts disable it           | Medium: setup guidance disagrees with package scripts or page metadata. Recommend corrected prose backed by the actual scripts.                                                                                                                                                                                                                                                                   | Rendered scaffold package scripts and page frontmatter                      |
| Node prerequisite is a fixed old major or tells readers to guess from repo pins                                                                  | Medium: compare `.nvmrc` first, then root `package.json` `engines.node`; quote the detected requirement. When neither exists, disclose the CLI minimum rather than claiming a repo pin.                                                                                                                                                                                                           | Repository Node pin and current scaffold renderer                           |
| Authored `docs/index.md` says it is generated, or contributing lacks the generated-files boundary                                                | Medium: distinguish authored `docs/index.md` from the generated app-root manifest. Document committed `docs/**/meta.json` and `oat docs nav sync` separately.                                                                                                                                                                                                                                     | `oat docs generate-index` and `oat docs nav sync`                           |
| Contents links omit `.md` despite real Markdown targets                                                                                          | Medium: recommend `.md`-suffixed source links, which the build transforms into routes.                                                                                                                                                                                                                                                                                                            | Authored Contents contract and docs-transforms links plugin                 |
| Contributing duplicates agent runtime rules rather than pointing to app-root `AGENTS.md`                                                         | Low: recommend consolidating runtime instructions into the existing agent guidance after approval; preserve custom rules.                                                                                                                                                                                                                                                                         | Docs-app guidance and contributing audience boundary                        |
| MkDocs setup says `setup-docs.sh` creates a virtual environment, config calls `tooling` an object, or index points at an assumed `docs/index.md` | Medium: verify the actual script and `.oat/config.json`. The scaffold installs with the selected Python, uses a framework string, and seeds index/config as `mkdocs.yml`.                                                                                                                                                                                                                         | MkDocs setup script, documentation schema and scaffold config               |
| Framework app has no app-root AGENTS.md                                                                                                          | Medium: missing current CLI scaffold capability. Recommend a CLI update and manual review of the canonical framework template; preserve existing files and never recreate a bootstrap-owned template.                                                                                                                                                                                             | Current CLI Fumadocs/MkDocs AGENTS scaffolds                                |
| Fumadocs pages inherit only layout/site metadata                                                                                                 | Medium: inspect the catch-all page and any relevant layout/metadata producers for page-specific title and description. Recommend manual app-shell review when absent. Accept equivalent valid Next `generateMetadata`, static per-page exports or customized layouts that produce correct page-specific metadata; do not demand the template's exact spelling.                                    | Current page template and Next Metadata API                                 |
| Reader Getting Started contains contributor toolchain setup                                                                                      | Medium: recommend moving setup into a contributor guide and restoring a first-safe-reader-result entry, with inbound links and old URLs reviewed.                                                                                                                                                                                                                                                 | Reader-first current framework scaffolds                                    |
| MkDocs/Material is presented as the actively developed default                                                                                   | Medium: cite Material's maintenance/security window through May 5, 2027 and Zensical successor from the [upstream changelog](https://squidfunk.github.io/mkdocs-material/changelog/). Distinguish Material from MkDocs core and retained pins from current upstream maintenance.                                                                                                                  | Material upstream support statement                                         |

A user-owned dynamic app may intentionally omit static export. Do not apply a static-export finding to it without evidence that static output is required. Likewise, verify commands and filenames against the target repository; these patterns identify discrepancies, not authority to overwrite customization.
