# Model guidance source status separation

## Context

The accepted model-selection matrix and newer release notes have different review states, so a ladder comparison could otherwise promote draft guidance into policy.

## Decision

Record accepted and review-pending guidance separately in the twelve-cell provider/tier audit, and leave Claude and Cursor ladder retuning to separate follow-up work.

## Consequences

The Astra Frontier update can ship without claiming acceptance of draft benchmark or provider-routing guidance; future model updates have an explicit evidence boundary.
