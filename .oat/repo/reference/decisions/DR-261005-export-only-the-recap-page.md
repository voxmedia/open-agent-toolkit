# Export only the recap page

## Context

Tracked recap support packages cluttered durable reference surfaces; the approved completion amendment required conserving every original while simplifying the reader artifact.

## Decision

Verify the complete original run and export one self-contained HTML page. Retain the complete manifest, sources and QA package in the local/configured archive; the report carries run and page hashes.

## Consequences

Summary and PR point to one tracked page. Legacy originals remain immutable evidence and retries adopt matching pages; conflicting destinations fail without overwrite.
