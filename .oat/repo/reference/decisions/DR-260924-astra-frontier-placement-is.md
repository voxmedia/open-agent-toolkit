# Astra Frontier placement is user-directed

## Context

GPT-6 Astra became a supported Codex target, but no representative OAT workload evaluation had established a local advantage over Sol.

## Decision

Include Astra high and xhigh in the bundled Codex Frontier recommendation while retaining Sol task-class defaults and describing Astra as a user-directed candidate.

## Consequences

Users can select exact Astra roles in Frontier. Broader default routing remains evaluation-gated and no performance or cost advantage is claimed.
