# Promote oversized Lite work in place

## Context

An interview can reveal that a Lite project is too large after useful context has already been captured.

## Decision

Promote the existing project to Quick while retaining its slug, branch, and authored Lite plan under references.

## Consequences

Quick discovery inherits the interview context and replans without discarding project identity or history.
