# Lite is a first-class workflow mode

## Context

Small single-sitting changes needed OAT planning and review without Quick's multi-session ceremony.

## Decision

Represent Lite as a registered project workflow mode rather than an untracked task concept.

## Consequences

Progress, resume, handoff, and routing remain available, while every mode-aware surface must recognize Lite.
