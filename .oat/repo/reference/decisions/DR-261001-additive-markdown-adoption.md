# Additive Markdown adoption

## Context

Populated documentation contains authored context and local ownership guidance that bootstrap must preserve; yes alone must not authorize its replacement.

## Decision

Require explicit adopt for populated Markdown trees. Add missing baseline index/contributing files only, preserve existing bytes and compatible config fields, and route malformed or incomplete content to analyze/apply.

## Consequences

Repeated adoption converges without duplicate guidance. Adoption establishes config and guidance rather than certifying full conformity; repairs remain separately scoped and partial write outcomes remain explicit.
