The conventions became executable

Configuration is source-aware

Commands now distinguish defaults, repository settings, local overrides, and environment values before suggesting a repair or choosing a path.

Claims require evidence

Skill declarations, provider reachability, archive state, and review records are checked against the surface that actually ships or executes.

Failure stays visible

Stopped lanes, rejected writes, partial synchronization, and recovery attempts retain categorical evidence instead of being summarized as success.

Gates test the real consumer

Focused controls are paired with uncached suites, package checks, and fan-in verification so cached or invented fixtures cannot stand in for execution.
