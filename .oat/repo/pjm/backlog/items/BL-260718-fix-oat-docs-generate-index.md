## Description

Bare 'oat docs generate-index' resolves its defaults (--docs-dir 'docs', --output index.md) against the invoking cwd. In a monorepo whose docs app lives elsewhere (this repo: apps/oat-docs), a bare invocation from repo root silently generates a stray ./index.md from the wrong tree instead of failing or locating the docs app. Evidence: 2026-07-18 wave-skills-promotion p04-t02 - the phase implementer ran the bare command per docs conventions ('regenerated by oat docs generate-index' in apps/oat-docs/AGENTS.md), got a stray repo-root index.md, and had to delete it and re-run with explicit --docs-dir apps/oat-docs/docs --output apps/oat-docs/index.md. Suggested fix: detect the docs app root (config key or marker file) or hard-fail when --docs-dir does not exist / contains no docs surface; align the AGENTS.md convention text with the exact flagged invocation.
