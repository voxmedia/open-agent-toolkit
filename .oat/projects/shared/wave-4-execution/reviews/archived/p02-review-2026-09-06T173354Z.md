## Rulings requested by the coordinator

### The `failed === 0` guard is correct, and its premise is real

I verified the factual claim through the engine rather than through the test
harness that asserts it:

- `countPlannedOperations` (`sync/sync.utils.ts:120-139`) counts collection
  plans only when the action is in `MUTATING_COLLECTION_ACTIONS` —
  `create-collection-link`, `adopt-collection-link`, `inherit-collection`,
  `detach-collection` (`sync.utils.ts:12-17`). `reject-collection` is **not**
  among them, so it contributes zero planned operations.
- `executeCollectionTransaction` (`engine/execute-plan.ts:463-475`) maps a
  `reject-collection` plan to a passive result with `status: 'rejected'`, and
  `executeSyncPlan` counts `'rejected'` into `collectionFailed`
  (`execute-plan.ts:981-984`), which flows into the returned `failed`
  (`:992-995`) → `coreFailed` (`apply.ts:404`) → `summary.failed`
  (`apply.ts:154`).

So `plannedOperations === 0 && failed > 0` is genuinely reachable in production.
Without the guard, a run that rejected a collection — and therefore exits 1 —
would have been described as "Manifest version refreshed; no content changes
required." and would have had its plan-body sentence stripped. The guard is
load-bearing, not defensive, exactly as the implementer's comment states.
F4 confirms it: dropping `summary.failed === 0` turns the new regression test red.

Two properties I checked that make the guard safe:

- **It cannot suppress a restamp.** The restamp is keyed off
  `scopePlan.versionSkew !== undefined` at `apply.ts:387`, computed long before
  `restampOnly` at `:528` and independent of it. `restampOnly` affects wording
  only, never the mutation.
- **The unsuppressed early return is unreachable.** `formatAppliedOutput`'s
  `scopePlans.length === 0` branch calls `formatSyncPlan` without suppression,
  but `versionSkew` is derived from `scopePlans` (`apply.ts:468-469`), so an
  empty `scopePlans` forces `versionSkew.length === 0` and therefore
  `restampOnly === false`. Safe by construction.
