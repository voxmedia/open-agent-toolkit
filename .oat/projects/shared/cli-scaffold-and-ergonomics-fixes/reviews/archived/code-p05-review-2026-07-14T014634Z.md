### Important

- **I1 — User-controlled titles can corrupt the managed backlog index** (`packages/cli/src/commands/backlog/regenerate-index.ts:92`)
  - **Issue:** `renderManagedSection` interpolates `item.title` directly into a six-column Markdown row. The new command accepts any non-empty single-line title (`packages/cli/src/commands/backlog/new.ts:120-127`), so a valid title such as `Parser | cache` creates a seven-cell row. A title containing `<!-- END OAT BACKLOG-INDEX -->` is more damaging because marker lookup uses unanchored `indexOf` (`regenerate-index.ts:142-143`), allowing the title text to be mistaken for the managed-block terminator on the immediate second regeneration.
  - **Impact:** `oat backlog new` can report success while leaving `index.md` malformed, and a subsequent regeneration can lose idempotence or rewrite the wrong managed bounds. This breaks the p05-t02 managed-index safety contract for user-controlled titles.
  - **Bounded fix:** Encode or escape every user-derived Markdown table cell before rendering (at minimum title pipes and marker-like HTML text), and make marker discovery require exact standalone marker lines. Add a focused `createBacklogItem` regression using a title with `|` and the literal end-marker text; assert a valid six-cell managed row, byte-identical immediate regeneration, and unchanged Curated Overview.
  - **Requirement:** p05-t02 — structured user-input safety; managed-index preservation/idempotence.
