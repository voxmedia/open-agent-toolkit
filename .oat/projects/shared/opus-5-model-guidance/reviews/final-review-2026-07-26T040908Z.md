- **Do not make xhigh the unconditional Cursor consequential default**
  (`.agents/skills/subagent-orchestration/references/provider-cursor.md:58`)
  - Issue: The matrix routes every consequential task to Sol xhigh plus Opus 5
    xhigh while its own floor note says consequence does not automatically
    require top effort. This contradicts the durable rule that reasoning depth,
    not consequence, selects effort and the same file's statement that xhigh is
    selective.
  - Fix: Start consequential Cursor work at the normal reasoning-depth route
    plus independent cross-family review, and reserve xhigh for an explicit
    reasoning-depth or evaluated long-horizon need.
  - Requirement: Discovery accepted finding 1 and plan task `p04-t01`.

- **Replace the stale Cursor deferral claim after the verified routes shipped**
  (`.agents/skills/subagent-orchestration/references/evidence-and-refresh.md:192`)
  - Issue: The canonical evidence policy still says Cursor Opus 5 selectors
    “remain deferred,” but Phase 7's live probe passed and six routes were
    shipped. This directly violates `p07-t03`'s acceptance check that no project
    artifact continue to claim the pin work is deferred.
  - Fix: State the durable rule prospectively—for example, selectors may ship
    only after a live probe verifies the listed controls—and note that the six
    named Phase 7 mappings met that gate.
  - Requirement: Plan task `p07-t03`.

- **Name the evidence packet used as the quantitative claim locator**
  (`.agents/skills/subagent-orchestration/references/evidence-and-refresh.md:164`)
  - Issue: The file publishes benchmark values and a derived `3.75x` result,
    then says an unnamed “dated evidence packet” is their locator. A portable
    consumer cannot find that packet, so these claims do not meet the same
    file's direct-locator and claim-level provenance contract.
  - Fix: Add the exact packet path and stable row-level locators for the quoted
    figures and derivation inputs, or remove the figures from the canonical
    summary.
  - Requirement: Plan task `p04-t05` and discovery success criterion 1.

### Medium

- **Use one required speed-measure contract across canonical references**
  (`.agents/skills/subagent-orchestration/references/model-selection-principles.md:127`)
  - Issue: The durable principles and provider references permit “time to first
    token or first useful action,” while the evidence policy requires TTFT and,
    when measurable, first useful action. This allows future evaluations to omit
    a metric that discovery explicitly included.
  - Fix: Use the evidence policy's wording everywhere, with a documented
    unavailable/not-reported value when a harness cannot expose a metric.

- **Retain a self-contained request-to-resolution probe manifest**
  (`packages/cli/src/providers/cursor/codec/catalog.test.ts:46`)
  - Issue: Tests require only a non-empty `probeName`. The retained hook payload
    identifies the probe and resolved model but not the probe definition's
    requested `model:` selector; those temporary definitions are deleted at
    `HEAD`. The mapping can therefore be associated incorrectly without a test
    failure, and the final evidence is independently checkable only by mining
    intermediate git history.
  - Fix: Preserve a sanitized manifest of
    `probeName/requested-selector/observed-model` tuples and assert the six exact
    tuples from `CURSOR_MODEL_PIN_MAPPINGS`.

- **Remove identity and machine paths from committed raw probe payloads**
  (`.oat/projects/shared/opus-5-model-guidance/references/g01-probe-hooks.jsonl:1`)
  - Issue: All 40 events retain a work email and absolute workspace/transcript
    paths. These fields do not support model-resolution verification and
    unnecessarily publish personal and machine-specific metadata.
  - Fix: Sanitize those fields while preserving timestamps, event names, probe
    names, resolved models, statuses, and correlation IDs needed for review.
