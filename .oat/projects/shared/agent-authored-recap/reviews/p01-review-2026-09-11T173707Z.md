### Important

- **The terminal guard can approve a forged or stale satisfied manifest** (`.agents/skills/oat-explainer-kit/scripts/check-terminal-outcome.mjs:84`)
  - Issue: The CLI reads only `manifest.outcome` and passes it to `checkTerminalOutcome`; manifest validation is used only for `skip/failed_attempt`. An independent control showed that a file containing only `{"outcome":"built"}` returns `{ok:true,intent:"generate",outcome:"built"}` without any artifact, QA, recipe, or byte evidence. The retry path compounds this: `runBundle` removes only `failure.json` before a changed-input rebundle (`bundle.mjs:309`), and `writeFailure` writes an interruption record without removing the old manifest (`bundle.mjs:284-299`). A reproduced changed-input rebundle followed by `writeFailure(..., "interrupted", ...)` left both records present, while the stale manifest still satisfied `generate`. This violates the run-root exclusivity and usable-artifact guarantees even though the later archive validator would reject corrupted package bytes.
  - Fix: For CLI `generate`, require a full manifest and validate the complete reusable-package assurance set: v2 contract, exact `project-recap` recipe/artifact identity, satisfied outcome, canonical fact-base/theme/artifact bindings, immutable bytes, exact inventory, and QA/artifact/outcome consistency. On a non-reused rebundle, remove or quarantine the prior manifest before changing package bytes, and ensure failure recording cannot coexist with a manifest. Add controls for a partial built object, corrupted package bytes, and changed-input rebundle interruption; keep a real recorded package as the accepted control.
  - Requirement: FR5, FR6.

### Medium

- **Pre-record failure sanitization can persist environment values and non-macOS absolute paths** (`.agents/skills/explainer-kit/scripts/bundle.mjs:290`)
  - Issue: Bundle and verify sanitize only the current cwd and `/Users/<name>`, so Linux, Windows, other temp paths, and environment values can remain in persisted causes.
  - Fix: Share the recorder's environment-value redaction and add cross-platform absolute-path normalization with injected-secret controls.

- **Multiple document roots still collide by relative locator** (`.agents/skills/explainer-kit/scripts/bundle.mjs:668`)
  - Issue: `uniqueByLocator` silently drops one of two separately supplied roots containing the same relative filename, including its hash and facts.
  - Fix: Namespace locators by declared root or reject ambiguous collisions explicitly; test equal relative names with different bytes.

- **Heading facts remain asymmetric** (`.agents/skills/explainer-kit/scripts/bundle.mjs:122`)
  - Issue: Source headings update context and are skipped as claims, while rendered headings are scanned for numbers and dates, so copied factual headings can fail tracing.
  - Fix: Index factual source-heading tokens or exempt structural heading tokens symmetrically; add numbered and dated heading controls.
