Keep the existing topology, base, resolution and changed-tip-config refusals. Add a command-level accepted control where the gate was introduced in the already-reviewed upper layer and only tip code moves.
  - Requirement: Project Brief Outcome 2's operator waiver for head movement, with other checks unchanged; brief contract 12.7 Stacked deliveries and 12.8 Operator waiver explicitly select the tip for the exit carrier. This is a regression in an existing accepted contract, not new hardening.
