Original request

The operator approved one tackle-backlog batch for wave-2 of the backlog review on 2026-09-27. The batch held twelve backlog items: the wave's queued items minus the recap-export lane, plus one new high-priority item to stop writing CLAUDE.md shims by default. Why the shim item jumped the queue: Claude Code now reads AGENTS.md on its own, and its agents-md plugin backs off for the whole project as soon as any CLAUDE.md is present. The shims OAT used to generate were now switching that plugin off.

Key agent decisions

  • Shims are opt-in, and OAT cleans up its ownBL-260927-make-claude-md-shims-opt, recorded as DR-260927-claude-md-shims-are-opt. The default strategy is none: sync writes no shim, removes the exact shapes OAT created, and warns about any other CLAUDE.md with two remedies. Reason: a leftover file silently turns off Claude Code's own AGENTS.md support.
  • The strategy lives in project configBL-260830-persist-instruction-sync was absorbed. The key documentation.instructionSyncStrategy sits next to documentation.instructionPointerExcludes, which governs the same commands, and the init prompt was dropped because opting back in is a single oat config set.
  • Commit the task ledger before review startsBL-260829-order-phase-bookkeeping-before. The phase ledger is committed before the per-phase reviewer is dispatched, so a fix child still starts from a clean tree. Reviews in phase three widened it: recovery-marker settlement moved into that commit, and the phase row stays nonterminal until fixes and gates settle. The item stays open because gates and skills run the installed release, so the change can only be watched on the next multi-phase project.
  • The recon validator ships with the recon packBL-260927-validate-recon-worker. The validator sits beside validate-packet.mjs and reuses its contract library. Tool authority is an allowlist rather than a denylist, and the artifact kind decides the output schema.
  • Guidance writers append; they never rewriteBL-260903-close-manual-only-agents-md. Only a missing managed block is appended. When OAT cannot prove the target file's identity, it falls back to the zero-write manual patch and names the real cause.
  • Archive rewrites references rather than warningBL-260909-rewrite-inbound-references. Only tokens that resolve to the moved item change, and edited files are swapped in through an exclusive temporary file so a hard link is never written through.
  • No oat tools where command for nowBL-260927-name-only-installed-pack. The operator postponed the command: the installed-pack guidance block and the new oat tools guidance cover the reported confusion, and existing list and info commands already show scope.
  • Phases run in sequence, not in parallel worktreesShared write sets made parallel lanes unsafe: project-guidance.ts, oat-doctor/SKILL.md, pjm/init.ts, help snapshots, the load-contract test, oat-reviewer.md, and the skill version pins.

As-built architecture

The wave added guards in front of commands that write to a repository. Each guard either proves a write is safe or falls back to reporting the problem without touching the file. The map shows the entry points, the guard each passes through, and what it may change.

Boundaries

  • Shim planner. Strategies are none, pointer, symlink, and copy; --strategy overrides a single run. Under none it never removes a hand-written file beside an AGENTS.md, CLAUDE.local.md, .claude/CLAUDE.md, excluded or docs trees, nested git checkouts, or any CLAUDE.md an AGENTS.md resolves to. A lone CLAUDE.md with no AGENTS.md is adopted into a new AGENTS.md and then removed.
  • Append writer. Hard-linked, unwritable, swapped, or non-regular targets get the manual patch. A new read-only oat tools guidance [--json] prints the managed block without installing anything.
  • Reference rewriter. Handles Markdown links, repository-root path strings, and whole-span code citations. Fenced code and working links elsewhere are left alone; forms it cannot resolve produce a warning.
  • Assignment validator. recon/scripts/validate-assignment.mjs checks one homogeneous wave per array, read sources inside allowed inputs and outside exclusions, a read-only tool allowlist, write paths inside the artifact kind's packet folder, and approved schema references.
  • Lifecycle skills. Quick-mode discovery routes straight to quick-start in next and progress; Lite records absorbed projects and backlog ids; implement commits the task ledger before the per-phase reviewer runs.

What the reviews caught

  • p02 C1: shim removal deleting a hand-written fileThe p02 review reproduced default sync deleting a hand-written CLAUDE.md whenever AGENTS.md was a symlink to it: the identical-copy check was comparing the file with itself. The first fix treated any CLAUDE.md the sibling AGENTS.md resolves to as unmanaged. The second extended that to links from other directories, checked both at planning and at apply time.
  • p04: a new validator authority gap every roundGate attempt one found read sources that were not bounded and arbitrary output schemas. Attempt two found mutation-capable tool names such as Bash accepted as read-only. The operator-authorized re-review found write paths not bounded to the packet folder. Each gap was fixed: a read-only tool allowlist, write paths pinned to the artifact kind's folder, and approved schema references only.
  • p05: the rewriter kept widening its reachThe p05 gate found a tracked Markdown symlink that let the rewriter write outside .oat/repo, suffix fallbacks that rewrote URLs and unrelated paths, and malformed angle-bracket links. The re-review then found code-span citations left unrewritten and corrupted footnotes. The rewriter now resolves every token and refuses symlinks and out-of-root paths.
  • Exit gate H1: writing through hard linksThe first exit-gate attempt found the rewriter truncating files in place, so an in-tree file hard-linked to an outside file would change the outside file. Task p05-t12 replaced files through an O_EXCL | O_NOFOLLOW temporary file and rename after an lstat device and inode re-check, proven with a hard-link fixture that fails when the guard is removed.

Known limits

  • BL-260829-order-phase-bookkeeping-before is not observed live yet: gates and lifecycle skills run the installed release, so its item stays open until the next multi-phase project.
  • The p04 phase gate never passed on its own; the final review and the exit gate covered p04 instead.
  • Case variants of CLAUDE.md are deliberately not warned about, because case-insensitive matching flagged real provider docs.

Outcome and follow-ups

What works now

  • oat instructions sync writes no shim by default, cleans up the ones OAT made, and tells you about any other CLAUDE.md that would switch off Claude Code's AGENTS.md support.
  • OAT guidance lands in AGENTS.md automatically when it is safe, and names the exact reason when it is not.
  • Archiving a backlog item repoints the links to it across .oat/repo.
  • Recon workers cannot launch with an assignment that reaches beyond its authority.

Upgrade note

After upgrading, oat instructions validate exits non-zero in a repository that still has old shims until oat instructions sync removes them. To keep shims, run oat config set documentation.instructionSyncStrategy pointer and sync again.
