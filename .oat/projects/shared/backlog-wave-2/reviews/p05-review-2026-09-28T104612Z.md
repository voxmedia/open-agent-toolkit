  - Fix: Exclude symlink files with `lstat()` or resolve and enforce the real target stays within the permitted scan root before reading or writing. Add a Git-tracked symlink fixture that proves an outside target remains unchanged.

### Medium

- **Suffix fallback rewrites URLs and unrelated item paths** (`packages/cli/src/commands/backlog/rewrite-references.ts:203`)
  - Issue: After relative resolution fails, the `.../backlog/items/<id>.md` suffix branch at lines 207-213 rewrites without checking where the token points. A scratch probe changed `https://example.com/backlog/items/BL-123.md` and `../../elsewhere/backlog/items/BL-123.md` to `archived/`, with no warning, although neither resolves to the moved file. This can corrupt source citations and links to another backlog.
  - Fix: Rewrite only tokens whose resolved target is the archived item's former path; leave URL schemes unchanged and warn for unresolved local forms. Pin both negative cases beside the successful relative-link fixture.

- **Angle-bracket links in the moved item become malformed** (`packages/cli/src/commands/backlog/rewrite-references.ts:366`)
  - Issue: The inline-link matcher passes the leading `<` into `rebaseTarget()`. In a scratch probe, `[angle](<./BL-other.md>)` became `[angle](../items/<./BL-other.md>)`, which is neither the original Markdown link form nor a valid path to the sibling item. The plain `[plain](./BL-other.md)` link in the same item rebased correctly.
  - Fix: Parse the optional angle delimiters separately from the target path, then reassemble the link after rebasing. Add an angle-bracket sibling-link assertion to the archive fixture.
