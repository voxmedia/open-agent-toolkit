This behavior predates p-rev1, and the operator's rule only covers files with content, so this is doc accuracy rather than a code defect.
  - Suggestion: Soften the sentence, for example "Removal never leaves a mix caused by a file with content; exact shims in excluded trees are not touched and are reported as leftovers". Alternatively, count exact shims outside the mutable scan as blockers too.
