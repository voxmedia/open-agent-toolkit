- **M1: Escape local filenames before emitting Fumadocs page directives** (`packages/cli/src/commands/docs/nav/fumadocs.ts:230`)
  - Issue: A Contents entry `[Hidden](!hidden.md)` becomes `pages: ["index", "!hidden"]`. Fumadocs 16.10.2 treats a leading `!` as an exclusion directive (`fumadocs-core/dist/loader-DrgsG18J.js:428`), so the listed page is absent from the primary sidebar. The reachability calculation at `fumadocs.ts:305` treats the same string as a literal basename, so sync and `--check` both report no unlisted pages or drift. The command therefore approves metadata that hides a page explicitly listed by the author.
  - Evidence: Root replay below produced `primary: ["index.md"]` for `!hidden` while sync/check returned empty `unlisted` and `stale` arrays. A normal filename appears, and `./!hidden` produces the actual `$ref: "!hidden.md"` node. All 70 current shipped docs appear in the primary tree; the defect concerns supported filenames rather than the current docs inventory.
  - Fix: Represent local page and folder references so they cannot be interpreted as Fumadocs DSL directives, while retaining ownership and reachability. The real loader accepts the local-path form `./!hidden`. Add a consumer-backed regression for a listed directive-prefixed filename and verify that check mode agrees with the primary page tree.
  - Requirement: `BL-260718-support-fumadocs-in-oat-docs`, p02-t01 strict Contents-derived sidebar and no false clean check.

- **M2: Include thorough-review omissions in Review Downgrades** (`.agents/skills/recon/scripts/render-packet.mjs:127`)

Review Downgrades contained only contested `claim-2`; unresolved `claim-1` and its redundant-verification omission were absent. The existing omission keeper at `two-source-publication.test.mjs:170` covers a core semantic review only.
  - Fix: Derive omitted claims from the incorporated assurance reviews and their actual immutable brief membership, including thorough review kinds, rather than only the three core kinds. Keep this a rendering fix, without restoring the retired forced-partial/omission-gap protocol. Add a validated thorough packet keeper alongside the core omission keeper.
