Original request

The operator picked this batch through tackle-backlog and approved it as proposed, as a single PR on branch wave/2026-09-30-backlog-wave-3.

Three priorities framed the wave:

  • Lead with the template break. Lifecycle skills copied templates from .oat/templates/, a folder that user-scope-only installs do not have, so those skills broke on every such install.
  • Teach Fumadocs to the navigation command. oat docs nav sync knew only MkDocs; it should write Fumadocs navigation too.
  • Fix recon publication. Fold in the packet-publication failure from the recon publication issue on GitHub, plus a Codex agent-limit note and one bounded retry.

Success criteria

  • Every acceptance criterion passes, with failing-first evidence for behavior changes and neutralize-and-restore proof for each negative control.
  • A user-scope-only install can run the lifecycle skills that copy templates.
  • oat docs nav sync writes committed meta.json files for apps/oat-docs, and the docs build passes.
  • Recon's production helpers produce a packet the validator accepts, end to end.
  • A branch that changes only test files passes the release version check.
  • The full Definition of Done passes and the PR ships at the new lockstep version with the items archived.
Fixed constraints

Templates resolve in repository, user, bundle order. Exit-gate waivers are operator-only and never self-issued under OAT_AUTONOMOUS. Recon briefs stay blind to the full manifest. The --force fix must leave every non-linked case unchanged.

Key agent decisions

Six choices shaped what shipped. Each pairs the reason with what it changed for users and later work.

p01

Skills copy templates through a CLI command

Why: skills should never need to know where a package manager put the CLI.

Effect: oat template resolve returns a path only for the repository and user tiers; --output copies the resolved content for any tier.

p02

Fumadocs navigation is strict

Why: a page missing from a Contents map should be reported, not shown silently.

Effect: generated meta.json lists exactly the Contents-map entries, and nav sync --check in the docs prebuild stops strictness from hiding new pages.

p03

Recon brief integrity uses rebuild-and-compare

Why: field-by-field binding let a new unbound field slip through in every review round and never converged.

Effect: the validator rebuilds each brief with the production generator and rejects any difference. A claim a review omits stays unresolved and is listed as not reviewed.

p03

Coverage gaps downgrade claims instead of blocking publication

Why: the extra per-statement gap check stopped valid packets from publishing.

Effect: the forced downgrade stays. unresolvedIssues now name claim IDs or a global scope, and legacy string entries read as global.

p04

The CLI owns the closeout check

Why: no skill script parsed the post-implement sequence, and complete-state already owned the final transition.

Effect: oat project closeout-check is reachable from every skill and testable at the transition itself.

wave

Sequential phases with one fan-in

Why: phases shared help snapshots, skill version pins, and docs pages, so parallel work would collide.

Effect: each skill gets one version bump, made by the first phase that touches it; the fan-in owns the lockstep release bump.

As-built architecture

Component boundaries

  • p01 templates. One resolver serves project scaffold, promote, PJM, backlog, and decision commands. Lifecycle skills copy through oat template resolve --output, and the Cursor-cloud skill's reversed order now matches.
  • p02 docs navigation. oat docs nav sync detects the framework. For Fumadocs it writes strict meta.json, turns cross-folder links into link entries, and takes titles from frontmatter or the first heading. A second run writes nothing.
  • p03 recon. The brief generator, reconciler, and validator agree. packet.md gains a Review Downgrades section, validation is linear in claim count, and retryLimit allows at most one admission retry per lane.
  • p04 closeout. oat-project-next recomputes exit-gate fingerprints with implement's exclusions. Waivers are append-only, operator-only, and offered before a generation is marked stale.
  • p05 small fixes. instructions sync --force keeps a CLAUDE.md that AGENTS.md resolves to, through a symlink, a chain, or a hard link. oat project dispatch record is validate-only, and skill validation reports YAML error locations and key types.

What happened along the way

  • p03 did not converge under review. Each root review round found a new High in the same family, an unbound brief field. The operator extended a fourth fix round past the cap, then approved a complexity-review simplification; the phase finished with a fix-loop count of 5.
  • During p03, PR #334 merged to main and took the lockstep and skill versions this branch had already bumped. The branch merged origin/main, resolved two test pin hunks, and re-bumped the collided skills above main.
  • p05 needed one bounded recovery: three test files outside its verification set still used the removed --project flag.
  • A p05 probe found that running worktree:init under a throwaway HOME made bundle-assets.sh copy the repository into its own staging until the disk filled, so probes switched to a frozen-lockfile install.

Limits

The Codex plan gate blocked on both allowed attempts with new, valid findings. The operator accepted the post-gate plan fixes without a third run and relied on the per-phase and final gates.

BL-261001-fail-closed-when-bundle-assets records why the test gate ran pnpm build with the real HOME first and then ran the isolated-HOME tests with --only: bundle-assets.sh never ran under a throwaway HOME.

Outcome

What now works

  • User-scope-only installs can run the template-copying lifecycle skills (p01).
  • The docs app's navigation is generated from Contents maps, and the docs build stops on stale navigation (p02).
  • Recon packets made by the production helpers publish, and coverage gaps downgrade claims instead of blocking (p03).
  • Closeout refuses to finish without a valid snapshot, and only an operator can waive a stale exit gate (p04).

What changes for users

  • Update the CLI together with the skills (oat tools update); the updated skills call commands an older CLI lacks.
  • Breaking: oat project dispatch record --project is gone. The dispatch rows in implementation.md remain the record.
  • Recon publication rejects any brief that differs from the production generator's output.
