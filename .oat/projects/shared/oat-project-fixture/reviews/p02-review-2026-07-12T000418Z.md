  - Issue: `const invokedPath = process.argv[1] ? fileURLToPath(import.meta.url) : null; if (invokedPath === process.argv[1])` compares the module URL against a non-normalized `process.argv[1]`. `journal.mjs:606-607` does the equivalent check but normalizes with `resolve(process.argv[1])`, which is more robust against relative/symlinked invocation paths.

  - Suggestion: mirror `journal.mjs` — `const invokedPath = process.argv[1] ? resolve(process.argv[1]) : null; if (invokedPath === fileURLToPath(import.meta.url))`.
