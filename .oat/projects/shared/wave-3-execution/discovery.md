- Reviewed history is append-only; every fix disposition stores a verification
  record; integration DoD gates run after fan-in before bookkeeping; configured
  cross-runtime gates run exactly as configured and `passed` is the only
  terminal gate-row state.

## Key Decisions

1. **Workflow mode: quick** — one S-sized lane with a complete external plan;
   the configured plan gate is the bundled pre-implementation artifact review.
2. **Solo lane, no parallel group** — a single ungrouped phase (`p01`) executed
   in the integration checkout's own worktree.
3. **Lockstep bump is part of the lane** — the plan's step 4 bumps all five
   public packages (0.2.34 → 0.2.35) together with `pnpm-lock.yaml`;
   `packages/cli/assets/public-package-versions.json` is regenerated by
   `pnpm build`.
4. **`pnpm lint` and `pnpm format` join the wrapper DoD** — the lane edits
   `tools/smoke/**`, which CI's gates do not cover.
5. **Dispatch policy:** managed / `high` (Claude `opus`) for implementer and
   reviewers; Sonnet only for bounded read-only recon. Configured gates run as
   now configured (plan gate and implement exit gate both under default
   same-family avoidance → a non-Claude target).
6. **Completion tail:** deferred to program close (`completion tail: deferred to
program close`; `recap: deferred to program close`).

## Rules adopted from Waves 1–2 (applied to this wave)

- Every root command uses absolute paths / `git -C`; no bare `cd`; a rejected
  commit does not stop an `&&` chain — verify `git log` before any launch.
- Drift refresh intersects the lane's write surface with the release
  change-detection roots and states the planned bump up front.
- Implementer briefs invoke each gate literally and capture per-gate exit codes
  to log files; the root reads the logs.
- Reviewer briefs for ordering/containment claims require delete- and
  reorder-class mutations; reviewer-designed adversarial probes stay mandatory;
  containment/override surfaces get a weaker-anywhere analysis.
- Configured gates launch detached (`nohup … & disown`) with a receipt file
  watched by the root; the selected target is verified in the `gate-start`
  line before walking away; a pre-child provider rejection is a boundary after
  one identical retry.
- `summary.md` is generated before any archive step; bookkeeping edits are
  asserted line transforms (never a `$1`-returning replace callback).
- Immutable explainer-kit packages are committed only with the formatter ignore
  in place (in `.oxfmtrc.jsonc`).
