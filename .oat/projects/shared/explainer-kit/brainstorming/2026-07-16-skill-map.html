Explainer Kit

Initial working map from the July 16 brainstorm. This records the starting hypothesis, not an approved architecture.

Two in-scope entry points

explainer-kit

Generic engine. No OAT/config dependency. Receives a fact base and destination contract through environment variables.

oat-explainer-kit

OAT adapter. Resolves project artifacts, lifecycle recipe, configuration, and trigger timing, then invokes the core.

1. ReconcileFederated sources → cited fact base

3. Draft + gateMarkdown narrative approval
4. BuildHTML deck, diagrams, hub
5. QA/publishStructural, render, cohesion, verify
