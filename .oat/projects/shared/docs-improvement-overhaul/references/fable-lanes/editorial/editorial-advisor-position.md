## (b) Recommended changes to the draft

1. **Fold E1 into a Quickstart rewrite instead of a new page.**
   Reason: Quickstart is a 2.8 KB router that calls itself "the canonical path-selection guide" and has no install command. A separate "first ten minutes" page would create two "start here" pages in a four-page section.
   Evidence: `getting-started/quickstart.md:104-106`; the install command is only at `tool-packs.md:429`. Keep every existing path and the "If You Are Unsure" block. Add Reusable Skills as a fifth path. Fix the CLI Utilities link.

2. **Merge E2 and E4 into one Reference page: "What OAT writes and how to remove it".**
   Reason: the exit procedure is the write inventory read backwards. One table (path | written by | scope | committed? | how to remove) halves both authoring and verification, and keeps the two from drifting apart.
   Evidence: the EM's ask #1 pairs them ("what to commit… and a full exit procedure"). F-34 already gives the removal semantics for packs.

3. **Before writing any new page, build one verified fact sheet, and verify it by running OAT, not only by reading source.**
   Reason: E1, E2/E4 and E3 rest on the same facts: what init, sync, tools install and project creation write in the repo, under `~`, and on `origin`. Five parallel verifications of overlapping facts is waste. Writes are exactly where reading source misleads. For example, `--no-hook` removes a hook despite its "Skip" help text, and init has `gitignore.ts` and `gitattributes.ts` modules that may touch tracked files.
   Evidence: `packages/cli/src/commands/init/index.ts:552-556,1392`; `packages/cli/src/commands/init/gitignore.ts`, `gitattributes.ts`. Method: a scratch git repo with `HOME=$(mktemp -d)` and a bare-repo `origin`. Record `git status --porcelain`, `find "$HOME"` and `git ls-remote origin` after each step, then run the removal steps and show a clean state. This is the "negative control" standard in the repo's AGENTS.md, applied to docs claims.

4. **Shrink E3 to "Pilot Provider Sync with one team" and make it depend on the fact sheet.**
   Reason: the EM said they would pilot Provider Sync only. A rollout page that also covers workflows multiplies unverifiable claims. F-14 (gate enforceability) moves out to E5. The page is day 1, what to commit (linking to change 2's table), what a teammate runs after cloning, mixed-tool provider enablement, a weekly drift check, and the exit (linking).
   Evidence: EM verdict, adoption review :174; F-22 is tied to F-08.

5. **Move R2 (cost) out of residuals in its run-count form.**
   Reason: the lead read F-18 as asking for prices. It asks: "how many agent runs a quick project triggers (implementer per phase, reviewer per phase, final review, gate)". That comes from the lifecycle skills and needs no prices. Put it as the "automatic agent runs" rows of E5's governance table. That is also the EM's ask #2: "every human checkpoint and automatic review".
   Evidence: adoption review :110 (F-18) and :179; verify against `.agents/skills/oat-project-implement/SKILL.md` and `reference/configuration.md:775-` (`autoReviewAtHillCheckpoints`, `autoArtifactReview.*`).

6. **Correct E5's framing of permission bypass.**
   Reason: as drafted, it implies unattended cross-model review requires bypass flags. The current text says built-in targets are conservative and OAT "should not bake dangerous provider permission flags into built-ins". Bypass appears only in user-defined "trusted target" examples. Targets are arbitrary argv, so a narrower permission set is possible in principle, but no one has shown that a restricted reviewer completes the review.
   What E5 can truthfully say:
   - (a) built-ins carry no bypass, and unattended runs with them may stop at permission prompts;
   - (b) an attended review needs no bypass: run the review yourself in the other tool;
   - (c) a narrower allowlist is the user's configuration and has not been verified by OAT.
     Publish a least-privilege recipe only if someone runs it end to end.
     Evidence: `workflows/advanced/workflow-gates.md:614-623,681-688`.
