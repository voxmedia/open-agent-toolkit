## Plain-Markdown path (#335)

The page's descriptions of the Markdown path are true:

- Declared config is checked first, then framework evidence.
- A populated plain tree gets an explicit adopt/audit/abort choice.
- `--yes` alone never authorizes adoption.
- The skill collects a title, root and description, but no app name, install, build or nav sync.
- The authored index stays authored.
- A generated inventory needs an explicit output outside the content root.
- Dry-run and partial results are reported honestly.
- Analyze treats the configured root literally as `docs-tree`.
- Apply runs no `generate-index` or nav sync for Markdown.
