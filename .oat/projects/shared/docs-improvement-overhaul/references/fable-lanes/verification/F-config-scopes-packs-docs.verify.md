## Undefined jargon for a junior-to-mid developer

- **"Layout keys" / "structural keys":** say "repo-wide path and policy keys" and list them.
- **"State keys", "`activeProject`", "`lastPausedProject`":** define as "which OAT project you have open in this checkout".
- **"Precedence", "built-in default":** fine. "Environment variable" needs the three names.
- **"Managed blocks"** (in `.gitignore`/`.gitattributes`/`AGENTS.md`): sections OAT owns between marker comments.
- **"Provider", "provider views", "provider sync", "agent tool":** Claude Code, Cursor, Codex, and so on, and the per-tool copies OAT generates.
- **"PJM" / "adopt project management":** the repo's backlog, roadmap and decision records under `.oat/repo/`.
- **"Guided setup", "fresh init":** fresh means no `.oat/` yet.
- **"Drift"** (hook): provider copies out of date with `.agents/`.
