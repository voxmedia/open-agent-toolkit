### Important

- **A claim omitted by every review still cannot become unresolved**
  (`.agents/skills/recon/scripts/reconcile-ledger.mjs:217`)
  - Issue: `incomplete` is gated by `supporting.length > 0`. If semantic,
    adversarial, and coverage results are complete but all omit the same
    provisional claim, `supporting` is empty, `incomplete` is false, and
    `coreComplete` is false. The claim remains `provisional` in revision two,
    and final shape validation throws `INVALID_PROVISIONAL_GENESIS`. This is
    precisely an incomplete per-claim review set, so p06-t01 remains incomplete.
  - Impact: a standard/thorough run cannot publish the required honest partial
    packet for a wholly unreviewed claim.
  - Fix: determine incompleteness from the absence of any required per-claim
    disposition without requiring an existing supporting disposition. For
    transition-eligible prior states, emit the legal transition to
    `unresolved`. Add an end-to-end control where all three review results omit
    the same provisional claim and compilation succeeds as `partial` with an
    explicit gap.
  - Requirement: p06-t01; design claim-state and honest-partial contracts.

### Medium

- **A coverage gap does not downgrade an already-verified claim**
  (`.agents/skills/recon/scripts/reconcile-ledger.mjs:279`)
  - Issue: removing `gap` from `coreComplete` prevents a supported claim from
    being promoted, but the `!coreComplete` branch leaves its prior state
    untouched. If the prior state is already `verified`, a new coverage
    disposition of `gap` returns a revision-two `verified` claim with no
    transition. Packet assurance then rejects that state because verified
    claims require `covered`.
  - Impact: reconciliation can still emit an internally inconsistent ledger
    and turn an otherwise diagnosable coverage gap into packet compilation
    failure. The deterministic boundary prevents false publication, so this is
    Medium rather than Important.
  - Fix: detect an explicit coverage `gap` before the `!coreComplete` early
    return and transition an already-verified claim to a contract-legal
    non-verified state such as `unresolved` or `contested`. Add a prior-verified
    negative control and compile the reconciled result.
  - Requirement: p06-t02; design graded-assurance contract.
