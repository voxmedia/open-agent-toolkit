### Important

- **Discover skill documents a `pnpm` fallback it is not allowed to run** (`.agents/skills/oat-project-discover/SKILL.md:7`)
  - Issue: The p04 plan requires the discover hook to use `pnpm run cli -- project split evaluate-signals ...` as a local-development fallback when installed `oat` is unavailable, and the skill documents that fallback at lines 282-286. But the frontmatter only allows `Bash(git:*)` and `Bash(oat:*)`; it does not allow `Bash(pnpm:*)`. In environments where `oat` is unavailable, the documented fallback is not executable by the skill.
  - Fix: Either add the narrow `Bash(pnpm:*)` permission to the discover skill frontmatter, or remove the fallback from the skill and update the p04 requirement/design to make installed `oat` mandatory for this hook.
  - Requirement: `p04-t01`

- **Non-interactive convergence path can still try to prompt instead of failing fast** (`.agents/skills/oat-project-discover/SKILL.md:369`)
  - Issue: The design says detected non-interactive split scope must record the detection and fail fast, and `p04-t01` says convergence uses the same CLI/non-interactive branches. The implementation adds a non-interactive branch only inside Step 9 mid-stream detection, then Step 11 always runs the final scope-check and says the prompt is required. If no mid-stream offer fired but the final convergence evaluation triggers, `OAT_NON_INTERACTIVE=1` still reaches an impossible user prompt instead of appending `## Detected Split Recommendation` and exiting non-zero.
  - Fix: Add an explicit `OAT_NON_INTERACTIVE=1` branch to Step 11 before the always-visible prompt: run the final signal evaluation, append the same recommendation section when confidence is `high` or `soft`, and exit non-zero. For `below`, proceed without prompting or document the intended non-interactive convergence behavior explicitly.
  - Requirement: `p04-t01`
