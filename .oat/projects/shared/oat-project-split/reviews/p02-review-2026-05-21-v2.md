### Important

- **Non-interactive detected splits only fail fast when `--non-interactive` is passed** (`packages/cli/src/commands/project/split/run.ts:158`)
  - Issue: The p02 integration plan requires the non-interactive detected case to work with `OAT_NON_INTERACTIVE=1`, and the design says detected non-interactive runs must fail fast rather than write projects. `run.ts` only checks `options.nonInteractive`; it ignores `context.interactive` and `dependencies.processEnv.OAT_NON_INTERACTIVE`. In a no-TTY or env-driven non-interactive run without the explicit flag, a `detected-mid-stream` or `detected-convergence` document proceeds to parent/child writes.
  - Fix: Derive an effective non-interactive value from the explicit flag, command context, and `OAT_NON_INTERACTIVE=1`; use it for the detected-origin fail-fast branch. Add a `run.test.ts` case that sets `processEnv: { OAT_NON_INTERACTIVE: '1' }` without `--non-interactive` and asserts no parent is written and the active discovery receives `## Detected Split Recommendation`.
  - Requirement: p02-t06 / p02-t07 / design non-interactive behavior

- **Resume proceeds without surfacing or confirming the recovered plan** (`packages/cli/src/projects/split/resume.ts:143`)
  - Issue: The p02 resume task and design require resume to surface the reconstructed persisted `SplitPlanDocument`/partial-state diff and continue only after user approval. `resumeSplit` immediately seeds missing children and finalizes the parent after validation, and `run.ts` automatically calls it whenever the parent directory exists (`packages/cli/src/commands/project/split/run.ts:177`). A stale-but-valid persisted plan can therefore resume further writes without the deliberate approval gate the workflow specified.
  - Fix: Split resume into detection/preview and confirmed continuation, or add an explicit `--resume`/`--yes` style confirmation path for CLI resume. In interactive contexts, print the recovered parent, child list, missing children, dependencies, and active child, then require confirmation before `seedChildren`/`finalizeSplit`; in non-interactive contexts, abort with guidance unless explicit resume confirmation is supplied. Cover both paths in `resume.test.ts` and `run.test.ts`.
  - Requirement: p02-t05 / design resume safety
