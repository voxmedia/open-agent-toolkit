Which renderer sees the authored content?

Recipe policy routes each artifact down one of two paths. The narrative path renders Markdown deterministically; the artistic path has the agent compose HTML. Both converge on the same safety, guideline, and approval checks, so freedom on the artistic path never bypasses validation.
