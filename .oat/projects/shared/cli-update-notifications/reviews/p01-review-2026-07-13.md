- **Concurrent invocations can duplicate registry checks and notices** (`packages/cli/src/app/update-notifier.ts:272`)
  - Issue: The service reads the cache, evaluates freshness, performs the fetch or warning, and only writes the updated snapshot afterward (lines 266-307). Two eligible processes that read the same stale cache before either write completes will both fetch; if an update is available, both can also warn.
