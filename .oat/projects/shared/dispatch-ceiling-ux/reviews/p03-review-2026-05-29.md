In `buildProviderResolution` (`packages/cli/src/commands/project/dispatch-ceiling/index.ts:296-334`), a supported provider (codex) only yields `advisory` when `value === null` — in which case the rendered `{value}` is null/unresolved, never `high`. A non-null codex value always compiles (`compileToDispatchArgs` returns `{ variant }`) → `enforced`.   - Fix: Change the example to reflect the real advisory shape, e.g. `Dispatch ceiling: unresolved (codex, advisory — ceiling set but no value resolved)` (value is null when codex is advisory), or replace it with the Claude not-honored-upgrade case which is the realistic supported-provider advisory path already shown at line 441.
